⚠ SAFETY NOTE: Methods marked Risk: High or Medium can PERMANENTLY
ERASE remote history or silently DISCARD other people's work. Never
run these on a shared/production repo without understanding what is
on the remote first (see Method 3). Every "safe" method below creates
a local backup branch (#BACKUP_NAME) before touching anything.

VARIABLES (replace before running):
  #REPO_URL     = Repo-https-link  (your GitHub repository URL)
  #MERGE_MSG    = commit message (no $ characters inside)
  #BACKUP_NAME  = backup branch name (default: backup-local)

Every command below starts by auto-detecting your current branch with
  BR=#(git symbolic-ref --short HEAD 2>/dev/null || echo main)
so it works whether your default branch is "main", "master", or
anything else — no hardcoding needed.

METHOD 0 — force (dangerous, NOT recommended) — ONE COMMAND
================================================================
REMOTE_URL="REMOTE_URL"; MERGE_MSG="merge: integrate remote, keep local version"; BACKUP_NAME="backup-local";
git remote get-url origin >/dev/null 2>&1 || git remote add origin "$REMOTE_URL"; git add -A; git commit -m "$MERGE_MSG" || echo "nothing to commit"; git push -u origin main --force && echo "$REMOTE_URL"

What: Completely erases remote history; replaces with your files.
When: Remote is completely empty and you are 100% sure.
Risk: HIGH — everything on the remote is permanently lost.
Reversible: NO — remote history cannot be recovered.
Speed: 10/10 (instant).
Commit Msg: No — this does not create a commit.
Alternative: Use Method 8 (force-with-lease) for a safety net.

METHOD 1 — -X ours (with custom message) — ONE COMMAND
================================================================
REMOTE_URL="REMOTE_URL"; MERGE_MSG="merge: integrate remote, keep local version"; BACKUP_NAME="backup-local";
git remote get-url origin >/dev/null 2>&1 || git remote add origin "$REMOTE_URL"; git merge --abort 2>/dev/null || true; git fetch origin || true; git rev-parse --verify origin/main >/dev/null 2>&1 && git branch -f "$BACKUP_NAME" origin/main || echo "WARN: origin/main not found"; git status --short; git add -A; git commit -m "$MERGE_MSG" || echo "nothing to commit"; git merge origin/main --allow-unrelated-histories --no-ff -X ours -m "$MERGE_MSG" || true; git push -u origin main && echo "$REMOTE_URL"

What: Conflicts auto-resolved in favor of your version; Vim never opens.
When: Remote is almost empty and you are in a hurry.
Risk: LOW — important remote changes are silently discarded.
Reversible: YES — via #BACKUP_NAME branch.
Speed: 9/10 (2-5 seconds).
Commit Msg: Yes — custom via -m.
Note: Remote-only files (LICENSE, etc.) ARE added to your tree.

REMOTE_URL="REMOTE_URL"; MERGE_MSG="merge: resolve conflicts, keep local files"; BACKUP_NAME="backup-local";

After resolving files — ONE COMMAND:
git push -u origin main --force && echo "https://github.com/Real4Nightmare/1NNZ_omni_GH_Projects.git"

What: The global standard. You resolve each file by hand.
When: The remote may contain important content.
Risk: NONE — you see everything.
Reversible: YES.
Speed: 3/10 (5-15 minutes, depends on number of conflicts).
Commit Msg: Yes — you write it with -m after resolving.
Advantage: Full transparency; nothing is silently discarded.

Commit Msg: No — this does not create a commit.

================================================================

  -s ours : only your file tree (LICENSE is not added)
  Both    : remote history is preserved.

METHOD 6 — --no-commit + review — ONE COMMAND (with pause)
================================================================
REMOTE_URL="REMOTE_URL"; MERGE_MSG="merge: reviewed and approved"; BACKUP_NAME="backup-local";
git remote get-url origin >/dev/null 2>&1 || git remote add origin "$REMOTE_URL"; git merge --abort 2>/dev/null || true; git fetch origin || true; git rev-parse --verify origin/main >/dev/null 2>&1 && git branch -f "$BACKUP_NAME" origin/main || echo "WARN: origin/main not found"; git status --short; git merge origin/main --allow-unrelated-histories --no-commit --no-ff && git status && git diff --cached --stat && echo "REVIEW ABOVE, THEN RUN: git commit -m \"$MERGE_MSG\" && git push -u origin main"

If everything looks good — ONE COMMAND:
git commit -m "#MERGE_MSG" && git push -u origin #(git symbolic-ref --short HEAD) && echo "#REPO_URL"

If something is wrong — ONE COMMAND:
git merge --abort && echo "ABORTED: #REPO_URL"

What: Merge without committing, so you can review exactly what is staged.
When: You want to be 100% sure what is going out before pushing.
Risk: NONE — full control.
Reversible: YES (via merge --abort).
Speed: 3/10 (5-15 minutes of review).
Commit Msg: Yes — you write it after review.

When: You must force but want a safety net.

Speed: 9/10 (2-5 seconds).
Commit Msg: No — this does not create a commit.
